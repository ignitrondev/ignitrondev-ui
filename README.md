# ignitrondev-ui

React component package for the IgnitronDev site. The visual system is the dark engineering landing page: square controls, hairline borders, Geist, and ignition amber.

```
packages/ui     @ignitrondev/ui
apps/docs       catalog at http://127.0.0.1:4178
```

```bash
bun install
bun run dev      # catalog
bun run check    # tsc
bun run test     # package tests
bun run build    # dist + catalog build
```

Package docs: [packages/ui/README.md](packages/ui/README.md).

This is the marketing-site kit. It is not Ignitron Clinical UI (odontogram, body map, and the rest of the foundry roadmap).
